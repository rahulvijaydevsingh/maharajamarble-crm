# Investigation: Amit feedback tasks and reminder

## Verified findings

- There is **one customer named Amit Sharma** (created 6 Oct at 16:32 IST).
- The customer’s expected feedback task was created three minutes later by the customer-creation flow:
  - **Task:** “Collect feedback from Amit Sharma”
  - **Due:** 19 Oct 2026
  - **Linked to:** Amit Sharma
  - **Reminder:** off; no bell reminder record exists.
- A separate task was created 38 minutes later:
  - **Task:** “Collect feedback from amit”
  - **Due:** 13 Oct 2026 at 10:00
  - **Linked to:** a different customer ID that no longer resolves to a customer record
  - **Reminder:** on, one hour before the due time
  - **Bell reminder:** exists and correctly opens this second task.

## Why the reminder has no customer details

The bell reminder itself is linked to the 13 Oct task, not directly to a customer. That task’s saved customer link points to a missing customer record, so the task panel has no related customer to show. The bell item still displayed because its reminder record retained the task ID and the text “Customer: amit.”

## Why there are two similar tasks

They were created as two independent records on the same day, not as a duplicate generated by one task:

1. The 19 Oct task matches the customer-creation follow-up workflow and is correctly linked to Amit Sharma.
2. The 13 Oct task was created later with a different, now-missing customer link. The available records do not prove whether it was manually created or came from an automation rule whose link target had been removed.

## Why only one has a reminder

The customer-creation form creates its standard review task with its reminder switch off unless the form’s default-reminders preference was active when the form opened. The Amit Sharma task was saved with reminders off, so no bell reminder was generated.

The separate 13 Oct task was saved with reminders on and a 60-minute offset, so the task-reminder synchronisation created the bell entry.

## No changes made

No records, settings, or code have been changed. The unresolved point is the origin of the missing customer record behind the 13 Oct task; there is no surviving customer row or customer activity history for that ID to establish whether it was deleted, never fully created, or was a stale link.

## If you later want this repaired

A safe repair would require an explicit decision for each record:
- either relink the 13 Oct task/reminder to Amit Sharma or dismiss/remove it as a stray task;
- decide whether the 19 Oct Amit Sharma task should have its reminder enabled;
- review the task-creation path that allowed a task to retain a customer ID whose customer no longer exists.
